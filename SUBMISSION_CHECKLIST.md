# Submission Checklist

Before you send us your submission:

## Repository
- [ ] Repository link works and reviewers can access it
- [ ] `cd backend && npm install && npm test` runs cleanly
- [ ] `cd backend && npm run dev` starts the API on port 4000
- [ ] `cd frontend && npm install && npm run dev` starts the UI on 5173
- [ ] README is updated with the new certificate endpoints and
      re-issue policy
- [ ] Certificate endpoints have a happy-path and one edge-case test
- [ ] At least one existing bug is fixed with a regression test
      (or manual verification note if frontend)
- [ ] `PROCESS_LOG.md` is filled in

## Silent working recording
- [ ] Screen recorded for the whole duration
- [ ] **No audio track**
- [ ] Paused during breaks rather than restarted
- [ ] File uploaded and link included

## Narrated walkthrough
- [ ] Up to 7 minutes, unedited, with audio
- [ ] Covers all five items in the README walkthrough brief
- [ ] File uploaded and link included

## Timing
- [ ] Total time spent is around 2 hours
